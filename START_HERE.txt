SOC L2 AGENT - FINAL DEMO BUILD
================================

RECOMMENDED COLLEGE DEMO
-------------------------
Open PowerShell in this folder and run:
    .\RUN_DEMO.bat

The launcher creates/uses .venv, checks the required packages (installing only when needed), creates .env when needed,
and starts Streamlit in local MOCK mode without requiring Wazuh, Splunk or Groq.

MANUAL RUN (PowerShell)
--------------------
    py -3.13 -m venv .venv
    .\.venv\Scripts\Activate.ps1
    python -m pip install -r requirements.txt
    Copy-Item .env.example .env
    python -m unittest discover -s tests -p "test_*.py"
    python scripts/final_validation.py
    python -m compileall -q .
    python -m streamlit run app.py

MANUAL RUN (Command Prompt)
---------------------------
    py -3.13 -m venv .venv
    call .venv\Scripts\activate.bat
    python -m pip install -r requirements.txt
    copy .env.example .env
    python -m unittest discover -s tests -p "test_*.py"
    python scripts/final_validation.py
    python -m compileall -q .
    python -m streamlit run app.py
